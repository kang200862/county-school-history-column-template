# 技术规范

## 拍摄

- 关闭美颜、滤镜、水印、自动增强
- 宁暗勿假；暗了可以提亮，假了没法回退
- 年代感靠**拍旧物本身 + 侧光影子 + 新旧并置**，不靠做旧、不靠黑白滤镜
- 不摆拍，不搬动景物

## 文件

| 项 | 要求 |
|---|---|
| 格式 | JPG |
| 长边 | ≥ 1600px |
| 单张大小 | ≤ 2MB（发布用）；原图另存不压缩 |
| 命名 | 见 `02_assets_and_authorization/命名与文件夹规范.md` |

## 保留

- **原图不覆盖。** 修图另存为新文件。
- EXIF 保留，作为「本人拍摄」的时间凭证。
- 微信传输会压缩，**不要把微信收到的图当原图**。
- 不截图代替照片。

## 备份

本地一份 / 云端一份 / 交接包一份，三份缺一视为无备份（见 `C-15`）。
