# 提示词包

所有提示词均使用占位符，不绑定任何真实学校、人物、事件。

使用时把 `[方括号]` 替换为你的实际信息；不要替换成真实姓名后直接公开。

---

## 1. 字段卡生成

```
你是校史栏目的编辑助手。请为下述选题生成一份「六模块字段卡」，全部使用占位符：
标题 / 导语 / 时间锚点 / 主体内容 / 现状照 / 来源与核实。

选题：[选题名]
已有素材：[素材类型]
待核实项：[待核实项]

要求：
1. 每模块给出字数上限与一句填写指引。
2. 不得虚构任何年份、人名、机构名。
3. 无法确认的一律写「[待核实项]」。
4. 输出为 Markdown 表格。
```

## 2. 送审单生成

```
请生成一份「送审包三联单」，三部分：送审联、回执联、存根联。

期号：[期号]
标题：[标题]
版本：v0.[版本号]
字数：[字数]
配图数：[配图数]
待核实项：[待核实项]

要求：
1. 三项勾选必须出现：零在校生信息 / 零政策评价 / 零未授权影像。
2. 审核链为：供稿人 → 指导老师 → 事实核对 → 终审。
3. 不出现任何真实姓名，一律用 [姓名] 占位。
4. 输出为可直接打印的纯文本。
```

## 3. 句子过筛

```
请逐句检查下面的文字，按五条删除标准判定：
1. 去掉后是否不影响信息量
2. 是否形容词堆叠
3. 是否在评价而非描述
4. 是否暗示「以前更好」
5. 是否涉及政策、补偿、决策、对错

原文：
[粘贴文本]

输出表格：序号 | 原句 | 命中条数 | 判定（删/改/留） | 改后
要求：不确定的判「留」，不要为了删而删。
```

## 4. 素材放行判断

```
请按七题流程判断这份素材能否使用，逐题回答「是/否」，再给结论。

1. 是否本人拍摄
2. 是否来自公开官方来源
3. 是否有明确来源链接
4. 是否包含可识别个人
5. 是否涉及在校生
6. 是否涉及未授权第三方署名
7. 是否已进入待确认池

素材描述：[素材描述]
来源：[素材来源链接]

判定规则：
- 第 5 题为「是」→ 弃用，无例外
- 第 1 或 2 为「是」且第 4 为「否」→ 放行
- 第 4 或 6 为「是」→ 待确认
- 其余 → 待确认

只输出：七题答案 + 结论 + 一句理由。
```

## 5. 纠错启事生成

```
请根据以下信息生成一则「更正启事」，不超过 100 字。

期号：[期号]
出错模块：[模块名]
原文：[原句]
更正为：[改后]
指正人署名方式：[真名/化名/不署名]

要求：
1. 不辩解、不推责、不写「但是」。
2. 只陈述：哪期、哪里错、原文、改后、致谢。
3. 落款不写具体人名，用 [指正人占位]。
```

## 6. 复盘

```
请根据以下信息做一期复盘，回答五个问题，不给建议、不做评价。

1. 本期哪一处被指出错误：[信息]
2. 哪个模块耗时最长：[信息]
3. 是否有凑字数的句子：[信息]
4. 如果供稿人不在，别人能否复现这一期：[信息]
5. 下期选题与素材是否已确定：[信息]

只输出五条结论 + 一句「本期是否算完成」。
判定标准：第 4 题为「否」，本期不算完成。
```

## 7. 新人上手

```
请为一位零经验的新人，生成一份 60 分钟上手清单。

可用资料：[已有资料清单]
对接人角色：[对接人]
第一期选题：[选题名]

要求：
1. 分四段：0–10 / 10–25 / 25–45 / 45–60 分钟。
2. 每段写「做什么 + 完成标准」，完成标准必须可判断是/否。
3. 第一小时的产出是**草稿**，不要求可发布。
4. 不出现任何真实姓名与校名。
```

---

## 使用注意

- 这些提示词产出的是**草稿**，不是可发布内容。
- 任何模型都可能编造年份与人名：**产出后必须逐条对来源**。
- 提示词本身也在 CC BY-NC-SA 4.0 之下。
