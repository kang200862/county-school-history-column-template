# 纠错入口模板

## 固定纠错文案（放在每期文末，不改）

> 本文如有年份、人名、照片错误，请在 `[纠错入口]` 指出。属实的在下期开头更正并致谢；涉及授权争议，立即撤稿。

## 字段

| 项 | 内容 |
|---|---|
| 收集方式 | `[纠错入口]`（只能有一个，写死不变） |
| 处理时限 | 收到后 **48 小时内**回复 |
| 回复话术 | 「收到，谢谢。您指出的这条我去核对原始资料，有结果就回您。已记下，不会漏。」 |
| 核实时限 | 回复后 **12 小时内**找到原始出处 |
| 登记位置 | 登记表第 `__` 行 |

## 更正启事格式

```
更正

[期号] 期 [模块名] 处有误，原文为「[原句]」，现更正为「[改后]」。

感谢 [指正人占位] 指出。
```

## 三条规则

1. **先回时间，不回结论。** 不承诺「一定改」。
2. **核实不了就标待核实**，不硬拗。
3. **授权争议立即撤稿**，不解释、不拖延，先撤再谈。
