# 审核流程模板

## 审核链

```
供稿人 → 指导老师 → 校志或事实核对 → 终审
```

四环节，不缺不越。**任环节不通过，当期不发，不争论。**

## 各环节检查项与通过标准

| 环节 | 检查项 | 通过标准 |
|---|---|---|
| 供稿人 | 六模块是否齐全；零在校生；零政策评价；素材是否全部有结论 | 三项勾选全勾，素材无「待确认」项 |
| 指导老师 | 事实是否与来源一致；表述是否会引起误解 | 逐条给出「可过」或「改哪句」 |
| 校志或事实核对 | 年份、机构名、人物身份是否准确；待核实项是否标注 | 每个待核实项要么补来源、要么保留标注 |
| 终审 | 是否可对外发布；是否涉及敏感表述 | 一句话结论：通过 / 修改后通过 / 不通过 |

## 留痕要求

| 项 | 要求 |
|---|---|
| 送审版 | 每版存 PDF，命名见 `命名与文件夹规范.md` |
| 回复 | 存截图（含时间） |
| 终审结论 | 存一句话结论截图 |
| 发布 | 存发布链接与截图 |

## 两句必须原样出现的话

1. 「任一环节不通过，当期不发，不争论。」
2. 「学校可随时叫停，我不保留独立发布渠道。」

## 逐步降级（如果四环节走不通）

四环节走不通时，降为两环节：**供稿人自检 + 一位事实核对**。
但**零在校生、零政策评价、素材有结论**这三条不降。
