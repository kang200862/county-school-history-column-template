# 选题池结构

只给字段结构，不含任何具体选题。

## 表头

| 选题名 | 问题句 | 可用素材 | 待核实项 | 风险点 | 是否可独立成期 | 下一步动作 |
|---|---|---|---|---|---|---|
| `[选题名]` | `[问题句]` | `[素材类型]` | `[待核实项]` | `[风险点]` | `□是 □否` | `[动作]` |

## 字段填写规则

| 字段 | 规则 |
|---|---|
| 选题名 | ≤12 字，不含评价词 |
| 问题句 | 写成**一个能用一句话回答的问题**，不写成标题 |
| 可用素材 | 只列**已判过四格**的素材；未判的写「待判」 |
| 待核实项 | 没有就写「无」 |
| 风险点 | 从 `06_delivery_and_handover/风险清单模板.md` 的 8 类里选 |
| 是否可独立成期 | 「是」的标准：不依赖任何外部人回复 |
| 下一步动作 | 一个动词开头，如「拍 3 张」「查来源」 |

## 判定标准

- 「是否可独立成期 = 否」的选题，**一次最多排在池子里 2 个**。多了会变成等别人。
- 每期做完，把池子里最难的那个降一级或删掉。
