# C-02 元信息栏字段定义

## 判定标准

- 七个字段全部必填。**「无」是填写，「空着」是没填。**
- 字段值一经发布不得随意变动；确需变动，须留痕（见 C-10）。

## 填空位

| 字段名 | 填写规则 | 必填 | 示例占位 |
|---|---|---|---|
| 期号 | 三位数，从 001 起，一期内不重复 | 是 | `[期号]` |
| 发布时间 | `YYYY-MM-DD`，发出后不再改 | 是 | `20XX-__-__` |
| 供稿人 | 实名或约定化名；不署名就写「不署名」 | 是 | `[供稿人]` |
| 审核人 | **实际看过稿并回复过的人**，口头转达不算 | 是 | `[审核人]` |
| 素材来源 | 逐项列出，禁止写「若干」「多方」 | 是 | `[素材来源链接]` |
| 待核实项 | 没有就写「无」 | 是 | `[待核实项]` |
| 纠错入口 | 一个固定渠道，写死不变 | 是 | `[纠错入口]` |

## 现成话术

> 「审核人这一栏不写『学校』，写那个实际回了我消息的人。」
