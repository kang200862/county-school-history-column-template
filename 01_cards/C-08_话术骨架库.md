# C-08 话术骨架库

## 判定标准

只给骨架，**不提供成品文案**。理由：成品会被照念，骨架才会被改写成本地口吻。

每格只填一句。填不出就删那一格，不要凑。

## 填空位（六类骨架）

**1. 首次开口**
`[我是谁]` + `[做什么，一句]` + `[不署名 / 归学校 / 送审]` + `[只问一个问题]` + `[给退路]`

**2. 交样片**
`[这是样本，不是成品]` + `[请看一处]` + `[指出哪里不对就够]` + `[不用给评价]`

**3. 被派活**
`[可以做]` + `[范围是 X]` + `[超出 X 的部分我不做]` + `[时间点]`

**4. 被沉默**
`[第 3 天同渠道一句]` + `[第 7 天换渠道]` + `[第 14 天只留「不打扰了」]` + `[跟满 2 次停]`

**5. 撤稿**
`[哪天撤]` + `[哪处有问题]` + `[核实前不再发]` + `[不解释细节]`

**6. 致谢**
`[本期致谢：X（线索）、Y（指正）、Z（实物）。]` + `[没人可谢就写「无」]`

## 现成话术

> 「骨架里每一格只填一句，填不出就删那一格。」
