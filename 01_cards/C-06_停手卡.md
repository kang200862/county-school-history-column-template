# C-06 停手卡

## 判定标准（触发任一条，按右列动作执行，不再讨论）

| 触发条件 | 动作 |
|---|---|
| 连续 `[N]` 期无人阅读且无纠错（建议 N=3） | 停更一期，只写内部复盘，不外发 |
| 学校书面叫停 | 立即停止；删除已发内容；24 小时内书面回复确认 |
| 供稿人开始评价政策 | 当期撤下改写；改不了就弃稿 |
| 供稿人开始承诺长期（「我会一直做」） | 当场把范围收回「只做到第 `[N]` 期」 |
| 供稿人无法完成交接（没有可交付的包） | 降级为「只归档，不再更新」 |
