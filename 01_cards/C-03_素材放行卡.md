# C-03 素材放行卡

## 判定标准（按顺序问，不跳题）

1. 是否本人拍摄？→ `是 / 否`
2. 是否来自公开官方来源？→ `是 / 否`
3. 是否有明确来源链接？→ `是 / 否`
4. 是否包含可识别个人？→ `是 / 否`
5. **是否涉及在校生？** → `是 / 否`
6. 是否涉及未授权第三方署名？→ `是 / 否`
7. 是否已进入待确认池？→ `是 / 否`

### 结论规则

- 第 5 题「是」→ **弃用**。不受其他任何答案影响，没有例外。
- 第 1 或第 2 题「是」，且第 4 题「否」，且第 3 题能填 → **放行**
- 第 4 题「是」→ **待确认**（取得书面同意后重判）
- 第 6 题「是」→ **待确认**
- 其余情况 → **待确认**
