# C-07 送审包三联单

## 判定标准

三联 = **①送审联（给对方）②回执联（对方填回）③存根联（自己留）**。
三联内容一致，用途不同。任缺一联，视为没有送审。

三项勾选**必须全勾**才可提交：
`□ 零在校生信息　□ 零政策评价　□ 零未授权影像`

## 填空位

### ① 送审联

```
编号 [编号]　　版本 v0.__　　稿件标题 [标题]
字数 __　　配图 __ 张
事实待核实项：[待核实项]

□ 零在校生信息　□ 零政策评价　□ 零未授权影像

审核链：供稿人 [供稿人] → 指导老师 [姓名] → 事实核对 [姓名] → 终审 [姓名]
每环节意见（一行）：
  1. ____________
  2. ____________
  3. ____________
结论：□ 通过　□ 修改后通过　□ 不通过
留痕：本单存 [存证位置]，同存回复截图
```

### ② 回执联

```
编号 [编号]　　收到日期 20XX-__-__
结论：□ 通过　□ 需修改　□ 不通过
一句话意见：____________
签署（姓名或工号占位）：[姓名]
```

### ③ 存根联

内容同送审联，不寄出，只归档。归档路径：`[存证位置]`
