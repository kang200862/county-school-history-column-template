# county-school-history-column-template

> **这是通用模板，不含任何真实校史素材。**

## 一句话

一套用于「县域中学校史栏目」的开源方法论文档：16 张 A6 卡片 + 空表头 + 排版规范 + 单页 HTML 模板，全部使用占位符，可打印、可分发给新人。

## 适用对象

- 想给母校做校史栏目的校友志愿者
- 学校里想组织学生社团做校史整理的人
- 需要一套「先能跑起来、再谈规范」的低成本流程的人

## 不包含什么

- 不含任何真实学校、人物、事件、年份、地址、照片
- 不含成稿、采访记录、联系人名单、送审记录
- 不含可直接发布的图文
- **不含法律意见**（见 LICENSE 说明）

## 使用顺序

1. **只读 `01_cards/C-01_字段卡.md`**，先把一期填出来（哪怕很糙）
2. 把它发出去一期（或送到第一个审核人手里）
3. 再从 `C-02` 往下读，按卡片顺序补

> 不要先读完 16 张卡再做。读完大概率就不会做了。

## 使用建议

- 打印成 **A6（105×148mm）** 卡片，一张卡一面，双面可印两张
- 发给新人时**一次只给 3 张**：`C-01`、`C-03`、`C-13`。给 16 张等于给 0 张
- 卡片是**做事时的辅助**，不是审批文件，也不是长期承诺

## 仓库纪律

- 卡片总数：**当前固定 16 张（C-00 ~ C-15）**
- 若确需扩展，**硬上限 24 张**，且必须先修改 `C-00_卡片规则.md`，在「扩容记录」里写清：哪个使用者在哪一步卡住了、为什么现有卡片解决不了
- 任何新增卡片不得因为「看起来更有用」而加，只能因为「有人真的卡住了」而加
- 本仓库不接受含真实校名、真实人名、真实照片的 PR
