# 命名与文件夹规范

## 基本格式

- **日期**：`YYYY-MM-DD`（例：`20XX-01-01`）
- **期号**：`P001`，三位，从 001 起
- **版本号**：`v0.1` 起，接受修改即升位（`v0.2`），定稿为 `v1.0`

## 素材命名

```
P___\_类型_主体_来源_四格.扩展名
```

示例（全部为占位）：

```
[期号]_照片_[主体占位]_[来源占位]_[A].jpg
[期号]_截图_[页面占位]_[来源占位]_[B].png
[期号]_扫描_[物件占位]_[来源占位]_[C].jpg
```

## 送审版本命名

```
送审_P___\_v0.__\_YYYY-MM-DD.pdf
```

## 归档命名

```
归档_P___\_YYYY-MM-DD.zip
交接包_YYYY-MM-DD.zip
```

## 私有文件夹（不进仓库）

```
01_待确认/     ← 未取得授权的
02_已放行/     ← 已取得授权或判为 A/B 的
03_自拍现况/   ← 本人拍摄，无人物
99_弃用/       ← 明确不用的，留档不删
```

**待确认与已放行绝不混放。** 混放是唯一会让「我以为有授权」变成「事实上没有」的路径。

## 禁止

- 同一文件出现两个版本号
- 文件名里出现空格与中英文标点混用
- 用「最终版」「最终版2」「真的最终版」
- 把日期写在文件名开头以外的任意位置
- 把真实姓名、手机号、班级写进文件名
